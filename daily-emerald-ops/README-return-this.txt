THE DAILY EMERALD, DISCUSSION DRAFT PACKAGE
===========================================

What is in this zip
-------------------
1. PROPOSAL-Daily-Emerald-Operations-DRAFT.docx
   The full proposed operating structure, written as a draft that is open
   to change. This is the document you present after the slides and mark up
   live with the team's feedback.

2. README-return-this.txt
   This file.


What to do
----------
1. Present the slide deck first to give the team the overview.

2. Open PROPOSAL-Daily-Emerald-Operations-DRAFT.docx and walk the team
   through it. Use the meeting facilitation guide to run the discussion.

3. As feedback comes in, EDIT this draft to reflect what the team agreed.
   Use the "Feedback and changes log" table at the end to capture who
   raised what and the decision. Then make the matching edits in the body
   of the document so the draft itself reflects the agreed version.

4. When the draft reflects everything the team agreed, RE-UPLOAD the edited
   PROPOSAL-Daily-Emerald-Operations-DRAFT.docx to the same Claude Code
   terminal and run PROMPT 2.

5. Prompt 2 will convert your approved draft into the finalised
   documentation package: a polished Operations Handbook PDF, the full set
   of paste ready markdown files, and an updated slide deck if the structure
   changed materially.

Nothing is final until you have run Prompt 2 on the approved draft.
